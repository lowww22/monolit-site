# Как залить сайт «Монолит» (коротко)

Vercel из России часто не работает — используем **Timeweb Cloud** (российский хостинг).

В проекте уже готово: сайт, фото, форма заявок, `Dockerfile`.

На рабочем столе также лежит архив: **`monolit-site-READY.zip`** (если скрипт успел его создать).

---

## Вам нужно сделать только это

### Шаг 1. Аккаунт GitHub (если ещё нет)

1. Откройте https://github.com/signup
2. Зарегистрируйтесь
3. Подтвердите почту

### Шаг 2. Загрузить код на GitHub (без терминала)

1. Откройте https://github.com/new
2. **Repository name:** `monolit-site`
3. Visibility: **Public**
4. **Не** ставьте галочки README / .gitignore / license
5. Нажмите **Create repository**
6. Нажмите ссылку **uploading an existing file**
7. Перетащите содержимое папки  
   `C:\Users\DANIL\Desktop\monolit-site`  
   **кроме** `node_modules` и `.next`  
   (или содержимое архива `monolit-site-READY.zip` с рабочего стола)
8. Внизу нажмите **Commit changes**

### Шаг 3. Timeweb — публикация

1. Откройте https://timeweb.cloud/my и зарегистрируйтесь
2. **Apps / App Platform** → **Создать**
3. Тип: **Dockerfile**
4. Подключите GitHub → репозиторий `monolit-site`
5. Ветка: `main` (или `master`)
6. **Deploy / Запустить**
7. Дождитесь «Готово»
8. Откройте выданную ссылку `https://….twc1.net` — это публичный сайт

### Шаг 4 (по желанию). Telegram для заявок

1. [@BotFather](https://t.me/BotFather) → `/newbot` → токен
2. [@userinfobot](https://t.me/userinfobot) → chat id
3. В Timeweb → переменные:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Перезапустите деплой
